# Cardinal Health | Workforce Reporting Case Study

Stevens team case study examining the shift from pushed HR reports to self-service reporting.

The team evaluated data consistency, access for authorized users, training, and adoption. The project analyzes an existing business case and does not claim employment, system implementation, or impact at Cardinal Health.

| Design decision | Evaluation question |
| --- | --- |
| Consistent reporting source | Can users stop reconciling duplicated reports? |
| Pull reporting | Can authorized users get reports when needed? |
| Training and rollout | What support is needed for adoption? |
